Mr. Freeze is a Discord bot that sends you notifications about your requests, such as when a request is received, approved or completed.

## Using Mr. Freeze

- Make sure your server allows direct messages from members, or the bot cannot reach you.
- Notifications are sent by direct message or in a channel set by the server admin.
- To stop notifications, contact the server admin or leave the server.
